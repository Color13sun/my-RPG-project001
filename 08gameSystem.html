１．変数詳細定義：『世界の物理定数』

　ツクールの「変数」を、この世界の「物理的な状態」として定義。

　var[001]：一時変数（ Temporary Variables / \( V_t \) ）
　　一時的に数値を代入するための変数。

　var[002]：肉体安定度（ Physical Stability / \( S_p \) ）
　　「命」という抽象的な概念を、タンパク質と魔那の「結合維持率」として定義。
  • 【システム仕様】
    • 範囲：\( 0 \sim 100 \% \)（初期値：\( 100 \)）
    • 基本減衰：フィールド移動中、\( 10 \)秒（\( 600 \)フレーム）ごとに \( -1 \, \)。
    • 加速要因：特定の強力な魔法（励起率が高い術式）を使用すると、廃熱により追加で \( -1 \sim -5 \) の即時ダメージ。
    • 臨界点：
      • \( S_p \le 20 \)：「共鳴ノイズ」状態。画面が紫に歪み、メニュー開閉速度が低下。
      • \( S_p = 0 \)：「熱力学的死（自爆）」。肉体が形を維持できず霧散する。いわゆるゲームオーバー。
  • 【世界観設定】
    • 複数の廃棄個体から継ぎ接ぎされた肉体を繋ぎ止めている「結合エネルギー」の強さ。
    • 本来「使徒」は空観大陸からの「調律信号」でこの値が維持されるが、地上では外部供給が途絶えているため、常にエントロピーが増大（崩壊）し続けている。
  • 【開発ノート】
    • HPとは別に管理される、真の寿命。プレイヤーに常に『薬を打たなければならない』という強迫観念を与えるための変数。
    • 序盤は減少速度をある程度速く設定し、プレイヤーに「抑制剤」の重要性を叩き込む。中盤、研究により減少を緩和する装備を実装予定。

　var[003]：魔那励起率（ Mana Excitation Rate / \( E_x \) ）
　　手のひらの魔那接続刻印マナ・コネクタから放出される魔力の「質」と「出力」を定義。
  • 【システム仕様】
    • 初期値：\( 100 \)（単位：\( W \) / ワット）
    • 計算式への関与：魔法ダメージ \( = \) 基礎威力 \( \times \: \: (E_x \; / \; 100) \)
    • 変動：抑制剤を使用すると一時的に上昇するが、肉体安定度が低いと、出力にムラ（乱数幅）が生じる。
  • 【世界観設定】
    • 説明：「魔那接続刻印マナ・コネクタ」が周囲の魔素をどれだけ激しく振動（励起）させられるかの指標。
    • 特徴：異世界の論理で「最適化」された術式を通すことで、本来\( \, 100 \, \)前後で頭打ちになるはずの出力が、\( \, 200 , \, 300 \, \)と異常な数値を叩き出すようになる。
    • 成長：拠点の「研究」でこの変数の上限値を底上げできるようにする。
    • 状態異常「魔那酔い」：短時間に魔法を使いすぎると付与されるデバフ。肉体安定度の減少速度が「\( \, 2 \, \)」倍になる。
  • 【開発ノート】
    • 『攻撃力』という曖昧な言葉を使わず、常に『励起率』と呼称することで、魔法を科学（物理）として扱う感覚を強調する。

　var[004]：異世界の知見（ Logic Awareness / \( L_a \) ）
　　主人公がこの世界の矛盾を観測するたびに蓄積される「生データ」。
  • 【システム仕様】
    • 微細な干渉：合成を成功するごとに\( \, +2 \, \)、失敗するごとに\( \, +1 \, \)、特定の「残骸」の解析で\( \, +5 \, \)されるなど、随時変動。
    • 成功率への寄与：「\( 1 \, \% \)の奇跡」を\( 1.1 \% , \, 1.2 \% \)と着実に積み上げるのは、この変数。
    • 影響範囲：
      • 合成成功率：基礎 \( 1 \, \% + L_a \)
      • 研究メニューの解禁：\( L_a \, \)が一定値を超えるごとに、より高度な「抑制剤」や「強化パーツ」のレシピが解放される。
  • 【世界観設定】
    • 「なぜこの世界は、あのアリストテレス的物理学で動いているのか？」という疑問に対する、主人公なりの解答の積み重ね。
    • この値が高まるほど、主人公の眼には世界が「数式」の羅列として視認されるようになる。
  • 【開発ノート】
    • ゲームの進行度（フラグ）を司る最も重要な変数。失敗すらも血肉にするシステムにすることで、１％の合成に挑み続ける意欲を維持される。
    • jsコマンド“$gameVariables.value(4)”をそのままダメージ計算式や成功率のスクリプトに代入。
  • 【獲得効率】（バランス指標）
    　　レベルデザインの参考として、プレイヤーがどのように知見を稼ぐかの想定値。
    • 合成の試行：
      • 成功：\( +2 \)（知見の定義）
      • 失敗：\( +1 \)（失敗データの収集）
    • ガラクタ漁り：
      • 通常ゴミ：\( 0 \sim +1 \)
      • 未知の残骸（レア）：\( +5 \sim +10 \)
    • 異世界の残滓（item[004]）：
      • 使用：\( +50 \)（劇的なパラダイムシフトそれまで当然とされてきた常識、ものの見方、価値観、思考様式などが、根本から劇的に変化すること。）

　var[005]：知見レベル（ Logic Protocol Level / \( L_{vl} \) ）
　　蓄積されたデータがある閾値を超え、「この世界の物理法則を完全にハックする新しい計算式」を構築した状態を指す。
  • 【システム仕様】
    • 不可逆な進化：レベルが上がると、これまで作れなかった「高純度抑制剤」のレシピが解放されるなど、ゲームのフェーズ（章）が進むトリガーとなる。
    • ステータスの再定義：知見レベルが上がるごとに、var[003]:魔那励起率（攻撃力）の「成長限界」が引き上げられるような設計にすると、育成の楽しさが生まれる。
  • 【世界観設定】
    • この変数の進展は、主人公がこの世界の「バグ（不条理）」をどれだけ体系化したかを示すマイルストーン。
    • 序盤は「生き残るための最低限の知識」としてサクサク上がり、中盤以降は「神の領域へのハッキング」として要求数値が跳ね上がる指数関数的な設計。
  • 【開発ノート】
    • もし var[004]\( \, \: \ge \, 100 \, \)ならば var[005]を\( \, 1 \, \)に、もし var[004]\( \, \: \ge \, 300 \, \)ならば var[005]を\( \, 2 \, \)にという判定を拠点（ラボ）に戻ったときに行う。
  • 【レベルアップ設計】
    1. レベルアップ必要値と解禁要素
      知見
      (\( \, Lv. \, \))      		必要累計知見
      var[004]      		 呼称
      （プロトコル名）      		解禁される研究・機能
      \( Lv.0 \)\( 0 \)未解析個体 基礎合成（成功率１％～）のみ実行可能。
      \( Lv.1 \)\( 100 \)古典力学的解釈 成功率補正が実感し始める。「抑制剤：改良型」のレシピ解禁。
      \( Lv.2 \)\( 300 \)熱力学的安定論 安定度減少を\( 1.2 \)倍遅くする。「内部冷却プラグイン」の作成。
      \( Lv.3 \)\( 700 \)電磁相互作用の再定義 戦闘用術式（雷系魔法）の効率化。ガラクタ漁りの効率UP。
      \( Lv.4 \)\( 1,500 \)量子確率論的介入 「１％の壁」を無視する特殊合成の解禁。強力な武具の生成。
      \( Lv.5 \)\( 3,100 \)次元解析・時空記述 重力操作、時空間ハック（範囲魔法）。「神の視点」への到達(?)
      \( Lv.6 \, \)以降も実装予定。

    2. 【実装メモ】レベルアップ判定ロジック
      [JavaScript]
      /**
      * 知見レベルアップ判定プロトコル
      * 現在の累積知見(v[3])に基づき、レベル(v[11])を更新する。
      */
      let currentK = $gameVariables.value(3);
      let currentL = $gameVariables.value(11);
      let nextL = currentL;

      if (currentK >= 3100) { nextL = 5; }
      else if (currentK >= 1500) { nextL = 4; }
      else if (currentK >= 700) { nextL = 3; }
      else if (currentK >= 300) { nextL = 2; }
      else if (currentK >= 100) { nextL = 1; }

      if (nextL > currentL) {
      $gameVariables.setValue(11, nextL);
      // レベルアップ演出
      AudioManager.playSe({ name: 'Up4', pan: 0, pitch: 100, volume: 100 });
      $gameMessage.setBackground(1);
      $gameMessage.setPositionType(1);
      $gameMessage.add(`【解析完了】論理階層が Lv.${nextL} へ深化しました。`);
      $gameMessage.add("新たな術式プロトコルが承認されました。");
      }

２．アイテム詳細定義：『地上の残滓と禁忌の成果物』

　すべての合成品および一部の素材は、以下の５段階の成功階級と、２段階の失敗階級に分類される。

　アイテムデータベース：設定共通ルール
  • アイテムタイプ： 基本的に「通常タイプ」に設定。
  • 消耗品： 完成品は「はい」、素材は「いいえ」。
  • 使用可能時： 完成品は「常時」または「メニュー画面」、素材は「使用不可」。
  • 範囲： 回復系は「味方単体」、それ以外はなし。
  • 価格： 基本的にTierが上がるごとに\( \, 10^{n} \, \)単位、あるいは倍数で増加。ただし、Tier0や失敗品は売却不可のため「\( \, 0 \, \)」に設定。

◆ アイテム品質等級表 ◆

  1. 成功階級：論理の洗練
    • Tier１：試作型／粗悪品（Lower）
      • 概念：暫定的な論理構築による、成功最低ライン。
      • 視覚： 灰色 (#888888) 。不純物が多く、不安定な状態。
    • Tier２：調整型／標準品（Standard）
      • 概念：適切に精製され、一般に広く普及している品質。
      • 視覚： 白色 (#FFFFFF) 。最も基準となる安定した状態。
    • Tier３：安定型／上質品（High）
      • 概念：成分の衝突が制御され、副作用を克服した純度の高い品質。
      • 視覚： 紫色 (#A335EE) 。魔那の波形が整い始めている。
    • Tier４：完成型／至高品（Master）
      • 概念：生体結合効率が理論限界に到達した、物理学的な極致。
      • 視覚： 金色 (#FFD700) 。聖職者が「奇跡」と呼ぶレベルの純度。
    • Tier５：超越型／特異品（Singular）
      • 概念：異世界の論理介入により、物理限界を超越した究極の形態。
      • 視覚： 水色 (#00FFFF) 。論理そのものが発光している。
  2. 失敗階級：論理の破綻
    • Tier\( \, \)-1：欠陥型／汚濁品（Defective）
      • 概念：成功に僅かに届かなかった「成功寄りの失敗品」。
      • 性質：狙った効果を得られるが、劇的な副作用を伴う。だが、研究データとしては成功品よりも価値が高い。
      • 視覚： 薄紫色 (#E2C6FF) 。
    • 廃棄物：焦げた汚泥（Burnt Sludge）
      • 概念：術式が暴走し、素材が炭化した完全な失敗作。
      • 性質：アイテムとしての効力は皆無だが、失敗のプロセスを解析することで僅かな知見が得られる。
      • 視覚： 焦茶色 (#6F4B3E) 。

　item[001]～item[009]：予備

　　管理の都合上、一応開けておく予備欄。


　item[010]～item[019]：体力回復用薬草
  • 【システム仕様】
    • 説明：赤く瑞々しい実をつける野草。実以外の草の部分に生体修復成分を含み、聖水と反応させることで「癒し薬」の原料となる。
    • 分離：合成素材。
    • 用途：「癒し薬」合成の主原料。
    • Tierごとの設定：
      ID等級　　名称価格説明文 \(L_a\)設定・仕様
      010Tier-1歪雫草ゆがしずくそう 0\C[6]【T0】\C[0]異常増殖した赤雫草。合成に使うと論理を汚染し失敗を招くが、過剰修復のバグデータとして研究価値は極めて高い。 20飢え人の死体からのみ採取可能。
      011Tier1枯雫草かれしずくそう 8\C[8]【T1】\C[0]成分が枯れかけた赤雫草。癒し薬の最低限の原料。生食すると喉を焼くほど苦く、回復量は微々たるもの。 2序盤のフィールド採取。
      012Tier1枯雫草かれしずくそう 8\C[8]【T1】\C[0]成分が枯れかけた赤雫草。癒し薬の最低限の原料。生食すると喉を焼くほど苦く、回復量は微々たるもの。 2序盤のフィールド採取。
  • 【世界観設定】
    • 　地上の至る所に自生する生命力の象徴。赤く瑞々しい実をつけるが、この実は人類にとって「必要以上の回復（過剰修復）」をもたらすため、摂取すれば肉体がそのエネルギーに耐えきれず崩壊する猛毒となる。致死量は豆粒ほどのサイズでありながら、わずか1個半という恐ろしさを誇る。
      　一方で、実は甘くて非常に美味しいとされており、その誘惑が犠牲者を絶やさない。人類が安全に利用できる回復成分は実以外の草・茎の部分に集中しているが、こちらは生で食べると非常に苦く、その苦痛に見合うだけの回復量（微量）も得られない。そのため、主に聖水を用いた精製プロセスの素材として扱われる。
      　最新の研究によれば、本来「猛毒」とされる実と「薬」となる草の両方を適切に調合・材料として用いることで、単なる癒し薬を遥かに凌駕する極めて高い回復効果を得られることが示唆されている。
  • 【開発ノート】
    • 　アイコンは「赤い実がついた緑の草」。テキスト内で「実の誘惑（死）」と「草の苦味（生）」を対比させる。知見レベル (\( L_{vl} \)) 上昇時、この「毒の実」から過剰なエネルギーを安全に抽出し草の成分と統合する特殊レシピを解禁し、上位抑制剤や最高級回復薬の核として再定義させる。

　item[002]：結晶化した魔那（ Crystallized Mana / \( M_c \) ）
  • 【システム仕様】
    • 説明：【合成素材】高密度の魔那が個体化した紫色の結晶。物質の結合状態を書き換えるための、強力な励起エネルギー源。
    • 分離：合成素材／触媒
    • 入手先：魔空生物の核、特定の機械の残骸
    • 用途：「抑制剤」合成の触媒（エネルギー源）
  • 【世界観設定】
    • 過剰な魔那が物理的な圧力を受け、個体化したもの。紫色の鋭い輝きを放つ小石。
    • 魔力に対する「着火剤」としての性能が極めて高く、これの質が合成の成功率を左右するが、不安定なものは触れるだけで爆発する危険を孕んでいる。
  • 【開発ノート】
    • アイコンは「紫色の結晶」。
    • 貴重品ではないが、残渣に比べて入手難易度を少し上げ、リソース管理の対象にする。

　item[003]：抑制剤：試作型（ Suppressant: Proto / \( S_p \)-\( 1 \) ）
  • 【システム仕様】
    • 説明：【消費材】肉体安定度を\( \, 30 \% \, \)回復。服用時に強烈な苦痛を伴い、副作用として一定時間、魔那励起率（魔法出力）が僅かに低下する。
    • 分離：消費アイテム
    • 効果：var[002]:肉体安定度を\( \, 30 \% \, \)回復。
    • 副作用：使用時に「魔那励起率」が\( 10 \)ターンの間\( \, 5 \, \% \, \)低下（不純物による出力低下）。
  • 【世界観設定】
    • 主人公が異世界の論理で、残渣（タンパク質）を魔那（エネルギー）で無理やり再重合させた液体。
    • 味・感覚：焦げたゴムのような悪臭と、喉を焼くような強烈な苦味。服用すると心臓が激しく脈動し、崩壊しかけていた細胞が悲鳴を上げながら「固定」される。
  • 【開発ノート】
    • アイコンは「濁った紫色の液体が入った試験管」。
    • 単なる「回復アイテム」としてではなく、「死なないために不快なものを飲む」という感覚をメッセージや演出で表現する。

　item[004]：異世界の残滓（ Anomalous Memory / \( A_m \) ）
  • 【システム仕様】
    • 説明：【特殊解析】異世界の論理体系が記録された記録媒体。解析することで「異世界の知見」が\( \, 5 \, \)上昇し、新たな研究が可能になる。
    • 分離：消費アイテム（貴重品）
    • 効果：var[004]:異世界の知見を\( \, +5 \, \)上昇させる。
    • 入手先：隠し宝箱、極めて稀にガラクタ漁りで見つかる。
  • 【世界観設定】
    • この世界の住人には「無意味なガラクタ」にしか見えないが、主人公には「かつての物理教科書」や「論理演算の断片」として視認される特異物。
    • 解析（使用）することで、この世界の物理定数をハックするための新たな計算式が脳内に書き込まれる。
  • 【開発ノート】
    • アイコンは「ノイズが走った本」または「壊れた基盤」。
    • レベルアップアイテムとしての役割。

３．コモンイベント詳細定義：『世界を駆動する論理の律動プロトコル』

　CE[001]：【生体維持】エントロピー減衰サイクル
　　プレイヤーに常に付きまとう「時間制限」と「死の気配」を制御。
  • トリガー： 並列処理（スイッチ[001]：ゲーム開始　ON時）
  • ロジック構造：
    1. 待機：\( 600 \)フレーム（\( 10 \)秒相当）。
    2. 演算：var[002]:肉体安定度を\( \, -1 \, \)。
    3. 状態チェック：
      • もし var[002] \( \le \) \( 20 \) なら：【警告】
        • 画面の色調変更（紫がかった暗い色へ）。
        • SEの演奏（心音・微弱なノイズ音）。
      • もし var[002] \( \le \) \( 0 \) なら：【臨界】
        • コモンイベント【緊急：肉体自壊】を呼び出す。
  • 【世界観設定】

　合成ロジック：品質決定と「限界突破」
　　合成結果は、投入された素材の平均品質ベースとして、確率的に決定される。

    　投入された全素材のTierの平均値を算出する。

    　　　 \( Tier_{base} \, = \, \) \( [ \frac{\sum Tier_{materials}}{N} ] \)

  2. 確率分布と「限界突破」
    • 通常成功：\( Tier_{base} \)のアイテムが生成される。
    • 限界突破（Critical Success）：
      • 確率：\( 0.01 \% \, \sim \, 0.1 \% \)（知見レベルに依存）。
      • 結果：\( Tier_{base} \, + \, 1 \, \)のアイテムが生成される。
      • 恩恵：普段より大幅に多い合成経験値（知見）を獲得する。
      • 制約：素材の質を無視した飛躍（例：Tier１同士からTier５が生まれる等）は起こらず、あくまで平均の１段階上の品質に留まる。
